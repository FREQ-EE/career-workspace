# Discovery workflow

Start from the current confirmed direction, practical constraints, capability evidence and calibration. Keep preferences separate from evidence of candidacy. Record salary, languages and qualifications as unknown when no attributable source establishes them.

Use current web research and follow promising results to direct employer application pages. A search snippet does not establish that applications are open. Record URL, check time, method and evidence. Access failures remain Unverified; confirmed closure is Unavailable.

Deduplicate canonical URLs and company/title identities. Add new suitable records to Inbox. Preserve every existing stage, note, task and history entry. Do not generate vacancies to fill a quota. Do not send applications or contact employers.

Manual, calibration and scheduled searches share one validated pipeline and one per-workspace execution lock. A cancelled or interrupted response is never saved as completed research. Background discovery requires explicit sharing and routine permission. After sleep, check whether one search is due.

Cloud tasks use the approved private search brief and append result deliveries. Their prompts, credentials and native scheduler confirmations must be configured explicitly; local configuration files do not create cloud tasks.
