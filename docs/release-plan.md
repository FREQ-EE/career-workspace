# Version 2 release contract

Approved: a private local workspace for Windows and macOS, with provider-neutral career records and explicit ChatGPT/Claude connections. The public starter must remain empty. No upstream private application or reference repository may be modified.

Release requirements: installable desktop shell; tray and sign-in launch controls; neutral and alternative dark/light palettes; laptop-responsive navigation; complete automatic saving; evidence import and review; resumable evidence/direction/constraints/calibration/routine onboarding; independent preference and capability assessment; current employer verification and deduplication; manual and periodic discovery; notifications; MCP access to career records; provider-owned account authentication; optional private cloud delivery; complete backup/restore; reviewed feedback; updates; strict public distribution audit.

The UI is centred on Home, Opportunities, Profile & Strategy, Documents and Settings. A conversation project is recommended, while confirmed records remain authoritative. Background work requires explicit opt-in. No application submission, employer contact, separately billed inference fallback or publishing of career data is part of the application.

Implementation checkpoints: persistence and contracts, provider protocol tests, search/import workflow tests, browser accessibility and responsive acceptance, production HTTP smoke tests, local and optional Worker builds, empty archive inspection, native builds on both target operating systems, clean initial public history and distribution publication. Live provider sign-in is established by each user's connection check and must never be claimed without actual confirmation.

Public history will begin from the final audited version-2 snapshot. Existing published commits are not retained as parents or development branches. No guarantee of removing external historical copies is made.
