# Career Workshop 2.0 public preview

A local career workspace with Windows and macOS desktop packaging, an explicit AI connection flow, resumable evidence/direction/constraints/calibration/routine onboarding, automatic saving and a responsive interface.

Includes user-defined CV versions, document preparation, manual and periodic discovery, independent employer checks, separate preference/capability assessments, tray or menu-bar operation, notifications, four appearance palettes, local MCP tools, complete backup/restore and an optional private cloud inbox.

The public distribution starts empty. Application submission remains a user action. Provider access and web-research capabilities depend on the selected account; run the real connection test during onboarding. Separately billed API fallback is not enabled. Existing provider paid-extra-usage settings remain under account control.

Desktop packages are unsigned and may require operating-system approval. Keep personal records in the separate application data directory. Updates preserve that directory.

This preview includes automated native startup and credential-store checks. Complete sign-in and a real search with the chosen provider before relying on a routine; automated protocol tests do not establish access for an individual account.
